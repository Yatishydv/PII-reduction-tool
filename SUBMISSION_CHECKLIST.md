## How to Reproduce

```bash
# 1. Install
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 2. Redact
python -m src.main --input "../Red Herring Prospectus.docx" --output "../redacted_output.docx"

# 3. Evaluate
python -m src.main --evaluate

# 4. Test
pytest tests/ -v
```

## What Was NOT Done (Honest Gaps)

- **Cloud deployment** — The API runs locally via `uvicorn`. Deploying to Render/Railway requires adding `Procfile` or `render.yaml`.
- **IPv6 support** — Not implemented (IPv4 only)
- **PAN / Aadhaar / DIN detection** — Not implemented (not present in the source document)
- **Multi-paragraph address detection** — Addresses spanning paragraph boundaries are not fully detected
